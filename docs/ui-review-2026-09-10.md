# UI review, 10 September 2026

The direction is a calm working interface with a clear task history, compact event rows, project/task navigation, contextual Git controls and category-based settings. Nerilo retains its paper, cobalt and terracotta palette and existing Astryx components.

## Changes

- Repository events and agent turns share a chronological rail. A turn has one expandable request row with its provider icon; review feedback expands inline. Exact GitHub links and recorded timestamps remain available. Repeated observations, legacy merge events and post-merge base updates do not create misleading duplicate rows.
- Changes opens a desktop side panel with file review and a contextual commit, branch, push or PR action. Narrow screens use a focused drawer. The task's original turn diff remains available separately. The header avoids a stale file count when checkout edits differ from the agent's original result.
- Settings has Connections, Environment and Appearance categories, aligned provider rows and secondary actions in menus. Shared dialogs have consistent spacing, bounded scrolling and keyboard focus containment.
- Home's branch menu selects the starting point. Presets and the finish line sit in task options. New projects begin with a repository or folder, with an optional inferred name and advanced preparation controls.
- Syntax colors are darker and more distinct in light mode. Minimum measured contrast across paper, code, added-line and removed-line backgrounds is 4.55:1. Existing WebGPU highlighting and exact text preservation remain intact.
- Fable 5.1 and Fable 5 are explicit Claude model choices with all five supported effort levels. A real Fable 5.1 structured request succeeded through the existing Claude login.
- Export now presents the resulting folder. Multi-line shell commands retain their complete script and separate output, while the display removes only a safely recognized shell wrapper. AI Git drafts prioritize the current diff over older task summaries.

## Remaining boundaries

Historical events only appear when recorded evidence is available. The interface does not invent missing actors, checks or review outcomes. A task containing multiple historical PRs with ambiguous old merge logs keeps those records separate.

At the time of this review, Git status did not report an authoritative remote HEAD, so reloading could offer Push again. This limitation was resolved on 12 September with a separate remote branch comparison and ahead/behind states. Fable access depends on the connected Claude account and installed CLI.

The verified build is running on the usual ports 5185/5186. Saved history was backed up before the schema update. Main-app navigation and the real PR14 history were checked after restart with no browser warnings or errors. The temporary QA servers were stopped.
