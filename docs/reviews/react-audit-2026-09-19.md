# React audit, 19 September 2026

Read all 55 React component files and both existing React helpers (`use-draft.ts` and `form-keyboard.ts`). Reviewed state ownership, effects and cleanup, request races, component identity, keys, rendering cost, client/server boundaries, imports, and keyboard behavior using the Vercel React Best Practices skill. Retained code where changes would not improve it.

There were 44 `useEffect` definitions and five `useLayoutEffect` definitions before this pass. There are now 32 and five, including shared hooks. Remaining effects synchronize with external services, browser subscriptions, timers, or the committed DOM. Shared queries also consolidate repeated fetch effects; the lower count does not mean every removed definition was unnecessary.

React's recommended Hooks lint rules now run locally and in CI, with dependency warnings treated as errors. The initial 35 diagnostics are resolved without suppressions. Heavy task, settings, PR, and file-browser views load on demand; component-library imports use supported typed entry points.
